## How I work

- **Measurable results first.** For clients, that means products that lift revenue and shorten response times.
- **Design that explains the model.** Every project card names the model behind it, because in AI products the model shapes the experience as much as the interface does.
- **Tools for my own team.** I build Claude skills that speed up research, documentation and prototyping:
  - `/create-slidedeck` and `/create-diagram` - on-brand decks and diagrams from one design system, used across the company
  - `/project-kickoff` and `/design-checkpoint` - project setup, missing-source checks and suggested methods
  - `/prototype-audit` - consistency, data sources, Nielsen Norman heuristics and accessibility
  - `/*-log` - user sessions, tests and design decisions documented straight to Confluence

## About this site

The site itself is a small design project. It's styled like a technical spec sheet - readout cards, dashed rules, crosshair markers and a single vertical spine connecting every section - to match the kind of precise, data-heavy tools I design.

- Designed in Figma, built in plain HTML and CSS - no frameworks, no JavaScript.
- Fully responsive, from large desktop to phone.
- The hero animation (scattered shapes settling into a price curve) is pure CSS and respects reduced-motion settings.
